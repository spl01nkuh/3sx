# Resources folder

3SX stores its temporary files in resources folder.

Location:
- **Windows**: `C:\Users\<username>\AppData\Roaming\CrowdedStreet\3SX\resources`
- **Linux**: `~/.local/share/CrowdedStreet/3SX/resources`
- **macOS**: `~/Library/Application Support/CrowdedStreet/3SX/resources`
- **iOS/iPadOS prototype**: the app's `Documents/resources` directory, visible through Files or Finder file sharing. See the [iOS guide](ios.md) for import instructions.
